# Support

Start with the documentation:

- [README](README.md) for installation and development commands
- [API documentation](docs/API.md) for the public TypeScript API
- [Architecture guide](docs/ARCHITECTURE.md) for module boundaries
- [Examples](docs/EXAMPLES.md) for usage patterns
- [Known limitations and roadmap](README.md#known-limitations)

Before asking a question, search the existing
[issues](https://github.com/mors119/copc-adapter/issues). Use a new issue when
the answer is not already documented and include the smallest reproduction you
can provide.

For suspected security vulnerabilities, follow [SECURITY.md](SECURITY.md)
instead of opening a public issue.
