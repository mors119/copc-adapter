# Security Policy

## Supported versions

Security fixes are intended for the latest version on the `main` branch and
the latest published package version. Older versions may not receive fixes.

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue or pull
request. Use GitHub's
[private vulnerability reporting form](https://github.com/mors119/copc-adapter/security/advisories/new)
when it is available. If the form is unavailable, contact a repository
maintainer privately through GitHub before disclosing the issue publicly.

Please include, when possible:

- the affected version or commit;
- a clear description of the vulnerability and its impact;
- reproduction steps or a minimal proof of concept; and
- any suggested mitigation.

We will acknowledge receipt when practical, investigate the report, and
coordinate disclosure and a fix with the reporter. Please allow maintainers
reasonable time to assess and address a report before public disclosure.

## Scope notes

COPC resources are commonly loaded from URLs controlled by an application or a
third party. When reporting a problem involving a particular dataset or host,
avoid sharing credentials, private URLs, or sensitive data in the report.
